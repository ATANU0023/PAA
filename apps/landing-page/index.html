Frequently Asked Questions

Do I need a high-end gaming GPU to run PAA? +
No! While PAA can run 100% locally on Ollama (Qwen 2.5 / Llama 3) if you have a GPU or external drive, it also includes a built-in Groq Cloud fallback that runs at 300+ tokens/sec on any lightweight laptop using a free Groq API key.
Is my code and browsing private? +
Yes. PAA is local-first. When running in Local Ollama mode, all prompts, thoughts, embeddings, and tool executions stay 100% on your machine with zero data transmitted to any cloud servers.
Can I pause or disable the pet's walking animation? +
Yes! Click the pet to open the circular orbit menu and click the green footprint icon to toggle Roaming Mode on or off. You can also drag the pet to any corner of any screen.
Is PAA open source? +
Yes! PAA is released under the MIT License. You are free to inspect the code, build custom tools, add new pixel art skins, or adapt it to your workflow.
